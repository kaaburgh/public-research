# NVMe namespace allocation ownership (P2-147/E142)
2026-11-27, verified extracted 1.24 and 1.32/1.33 PE. No hardware tests.
Old namespace installation 2277..22fc allocates controller page size (typical 4 KiB, memory type6) into namespace+20 and maps into +28/+30. New 2254..2283 uses controller preallocation record+50 for namespace+20, each namespace may map same host page. PRP builder 5db4, 5f43..5f9b copies namespace+20/+28 to work pointers and fills 64-bit physical page addresses into this page. It stores device mapping into command+20. Namespace cleanup old16ed unmaps then1700..1725 frees page; new16f6..1706 unmaps but no per-namespace page free. Controller record retains page.
Old metadata paths 25ab..2604 allocate 512 pages type6 per qualifying namespace, fields +1118 or +1140 with size +1130 or +1158. New252b..2568 checks record+60, allocates fallback 512 pages if zero and required; 258b..25c6 copies shared pointer into same namespace fields. For namespace with metadata, 60c6..6166 maps common buffers, 618d..61ea adjusts transfer length, 62af..6343/6438..64b7 transform data, 6427 submits command. New namespace removal does not free shared 2 MiB (old1755..17ac freed per-namespace pointers); controller path2662..2688 frees record+60 if none of installed namespace paths marked use; c3d..c6b frees if no namespace children. Note allocation can precede knowledge of need. New initial early allocation result may be null; metadata path fallback checks status, so no blanket unchecked-null claim.
Multiple qualifying namespaces share host pages in new design. Allocation-only estimate: for k qualifying namespaces, old k PRP pages + k 2MiB buffers, new 1 PRP page + 1 2MiB buffer, conditional on all allocations and identical page size. Ignores other queue allocations, DMA maps, OS handoff, record retention and temporary allocations. No material saving predicted from these two categories alone for k=1. Synchronous BlockIo wrapper 2820/284c calls5fc4 and command routine659c; no explicit lock/TPL raise found in these direct wrappers; upper-layer serialization, SMM ownership and other call paths not proven.
